# 1967–2014 程式稽核

未發現日期篩選、每日複利、費率換算或期貨換月的程式錯誤。早期模型已改為：

- 1967–1998/07：`2 × 含息報酬 − 歷史短率 − 費用`。
- 1998/07–2014/10：`2 × 台指期報酬 + 歷史 RP − 費用`。
- 2014/10 後：00631L 實盤。

已移除兩項偏誤：1967–2002 固定 3.1036% 股息，以及把 2004–2025 期貨相對報酬平均回填至期貨上市前。

測試會核對：

1. 1967–2001 與 1986–2000 股息累積倍率。
2. 央行 1974、1981、1998、2014 關鍵利率值。
3. 1969–2014 年化與最大回撤固定結果。
4. 2014 後每一日正二報酬等於 00631L 還原實盤。
